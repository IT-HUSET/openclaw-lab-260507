# Customization And Personalization Lab

Use this after your OpenClaw gateway is running.

There are two tracks with the same core ideas:

- [Basic customization lab](customization-lab-basic.md) — dashboard-first, best for participants who are less comfortable with terminals, SSH, config files, and command-line tools.
- [Advanced customization lab](customization-lab-advanced.md) — more technical, best for participants who want to edit workspace files, inspect commands, and experiment with heartbeat, cron jobs, personal-assistant setup, and a knowledge vault.

Both tracks cover:

- What onboarding configures.
- What first-run bootstrapping does when the Web UI opens and the assistant wakes up.
- `AGENTS.md`, `BOOTSTRAP.md`, `IDENTITY.md`, `SOUL.md`, `USER.md`, `MEMORY.md`, `HEARTBEAT.md`, and `knowledge/`.
- How to think agentically: delegate, remember, monitor, schedule, and ask for approval before risky actions.

The bootstrap screen looks like this:

![OpenClaw Web UI bootstrap screen](../../assets/webui-bootstrap.png)

## Which Track Should I Use?

Choose the basic track if you want to learn the concepts mostly through chat.

Choose the advanced track if you are comfortable with terminal commands, SSH, markdown files, and copying small config snippets.

Facilitators can mix tracks in the same workshop. The basic track is not a lesser version; it teaches the same operating model with less operational detail.
