## Lab Prompts

Use small, low-risk exercises first:

```text
Summarize the files in your workspace. Do not modify anything.
```

```text
Create a short markdown note in the workspace with three ideas for automating a weekly team routine.
```

```text
List the tools you are allowed to use and ask before running shell commands.
```

## Facilitator Notes

- Keep the first exercise read-only.
- Watch for participants pasting real credentials into shared chat or screen shares.
- Stop and discuss before enabling messaging channels.
- Save public internet exposure and production hardening for a separate session.
